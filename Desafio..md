## 🎯 Desafio Criativo: Simplificando Tarefas e Ganhando Foco com IA
O desafio final pede um **prompt final claro e útil usando ia** seguindo os passos propostos, deixo abaixo o prompt utilizado nesse desafio:
```
Quero que a IA gere uma lista de atividades para um desenvolvedor de jogos, com o objetivo de melhorar e planejar a construção de um jogo indie.

Considere o seguinte contexto: rotina de tarefas. O conteúdo deve ter o formato de lista simples. Evite linguagem técnica. 
```
O resultado obtido através do uso do prompt definido segue abaixo:
```
1. Planejamento Inicial

Definir a ideia principal: Escrever em poucas frases qual é a história, a sensação do jogo e quem é o jogador.

Mapear as mecânicas centrais: Listar o que o jogador faz a maior parte do tempo (ex: pular, atirar, resolver enigmas).

2. Testes e Prototipagem

Criar um teste simples (Protótipo): Montar uma versão inicial rápida, usando formas básicas, apenas para sentir se a diversão funciona na prática.

Desenhar os cenários e fases: Rascunhar no papel o caminho que o jogador vai percorrer e os desafios que vai encontrar.

3. Conteúdo e Arte

Listar os elementos visuais: Fazer uma lista de todos os personagens, cenários, objetos e menus que precisam ser desenhados.

Organizar os efeitos de som e música: Listar as faixas musicais e os barulhos necessários (passos, tiros, cliques de menu, impacto).

4. Gestão e Rotina

Dividir o projeto em tarefas diárias: Quebrar objetivos grandes em tarefas pequenas que possam ser concluídas em poucas horas.

Testar com outras pessoas: Pedir para amigos ou outros desenvolvedores jogarem e anotarem onde tiveram dificuldade ou se divertiram.

Ajustar os detalhes e o equilíbrio: Regular a dificuldade, a velocidade dos personagens e a resposta dos controles com base nos testes.

5. Divulgação

Preparar o material de divulgação: Criar capturas de tela, vídeos curtos e uma descrição simples para mostrar o jogo na internet.
```
